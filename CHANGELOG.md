## [0.1.0-alpha.1] - 2026-10-12

Первый публичный билд. Мод загружается, ведёт собственные логи и работает в сетевом контексте
Entangled Worlds. Игровой логики БР пока нет — это фундамент под M2.

### Added

- Каркас мода: `mod.xml` с баннерами режима (`bg` + `fg`) и `init.lua` с хуками жизненного цикла
  (`OnModPreInit`, `OnModInit`, `OnModPostInit`, `OnWorldInitialized`,
  `OnMagicNumbersAndWorldSeedInitialized`).
- Собственное логирование в файл — по одному на контекст:
  - `logs/init.log` — контекст мода;
  - `logs/ew.log` — сетевой контекст Entangled Worlds.
  В шапке — время запуска, версия Modding API и список активных модов, чего достаточно для
  сравнения установок двух машин.
- Сетевой слой на базе [Quant's Entangled Worlds](https://github.com/IntQuant/noita_entangled_worlds):
  модуль исполняется в контексте EW, доступны `ctx.my_id`, `ctx.host_id`, `ctx.is_host` и состав сессии.
- Хуки `on_local_player_spawn` и `on_client_spawned`, а также кэш состава сессии (ростер)
  с отслеживанием входа, выхода и дисконнекта игроков.
- Первый RPC (`hello`) через `ew_api.new_rpc_namespace("synergis")` — проверен локально
  (`opts_everywhere`), ждёт проверки вдвоём.
- Документация по разработке: `docs/00`–`docs/08`.

### Известные ограничения

- Нужна **обычная** сборка игры (`noita.exe`), не dev: на `noita_dev.exe` не работает NoitaPatcher
  из EW, и синхронизация сущностей не поднимается.
- Нужны включённые **unsafe mods** (`request_no_api_restrictions="1"`) — из-за файлового
  логирования. По этой же причине мод нельзя выложить в Steam Workshop.
- Все игроки должны иметь одинаковый набор модов и одинаковые версии.
- Название и описание режима в меню пока не переводятся (см. `docs/08`, §7).
